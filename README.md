## Быстрый запуск

Всё делается одним файлом `app.py`.

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python app.py seed --reset      # база, структура разделов и демо-контент
python app.py                   # http://127.0.0.1:8000
```

Админка: <http://127.0.0.1:8000/admin> — логин `admin`, пароль `filarmonia2026`.

### Команды

| Команда | Что делает |
|---|---|
| `python app.py` | запускает сайт на порту 8000 в режиме разработки |
| `python app.py --port 5000` | другой порт; есть также `--host` и `--no-debug` |
| `python app.py seed` | создаёт таблицы и наполняет, не трогая уже введённое |
| `python app.py seed --reset` | очищает базу и наполняет заново |
| `python app.py test` | прогоняет проверку основных сценариев админки |
| `python app.py --help` | справка по командам |

### Демо-контент

Демо-афиши, фотографии и ролики рисует модуль `filarmonia/demo.py` — он вызывается
командой `seed`. На боевом сайте их заменяют настоящие файлы, загруженные через админку.

Шрифты берутся из системы (DejaVu на Linux, Georgia и Segoe UI на Windows).
Для роликов нужен `ffmpeg` — системный либо `pip install imageio-ffmpeg`. Без него
наполнение проходит без ошибок, просто без видео: на главной останется кадр-заставка.

## Устройство проекта

```
filarmonia/
├── app.py                  единственная точка входа: сайт, seed, test
├── config.py               настройки (читаются из переменных окружения)
├── requirements.txt
├── .env.example            образец переменных окружения
├── render.yaml             тестовое развёртывание на render.com
├── DEPLOY-RENDER.md        порядок действий для render.com
└── filarmonia/
    ├── __init__.py         фабрика приложения, фильтры шаблонов
    ├── models.py           модели базы данных
    ├── public.py           маршруты публичной части
    ├── admin.py            маршруты админки
    ├── utils.py            даты по-русски, загрузка файлов, разбор ссылок на видео
    ├── seed.py             первичное наполнение базы
    ├── demo.py             генератор демо-афиш и роликов
    ├── selftest.py         проверка основных сценариев админки
    ├── templates/
    │   ├── public/         шаблоны сайта
    │   └── admin/          шаблоны админки
    └── static/
        ├── css/site.css    стили сайта
        ├── css/admin.css   стили админки
        ├── js/site.js      меню, версия для слабовидящих, баннеры, галерея
        └── uploads/        загруженные файлы
```

### Модели базы

`User` · `Setting` · `Page` · `MenuItem` · `Venue` · `Category` · `Event` · `EventBadge` ·
`MediaItem` · `Album` · `Collective` · `News` · `Document` · `Banner` · `Appeal`.

`MediaItem` — общая таблица фото и видео: привязывается к событию, коллективу, новости
или альбому. `EventBadge` — всплывающие баннеры на афише события.

### Настройки

Все параметры читаются из переменных окружения — см. `.env.example` и `config.py`.
Файл `.env` приложение само не читает: переменные задаёт systemd (`EnvironmentFile`),
панель хостинга или оболочка.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `SECRET_KEY` | `change-me-in-production` | подпись сессий |
| `DATABASE_URL` | SQLite рядом с `config.py` | строка подключения к базе |
| `UPLOAD_FOLDER` | `filarmonia/static/uploads` | каталог загруженных файлов |
| `SESSION_COOKIE_SECURE` | `0` | `1` — cookie только по HTTPS |
| `TRUST_PROXY` | `0` | `1` — брать протокол и адрес клиента из `X-Forwarded-*` |
| `SITE_NOINDEX` | `0` | `1` — закрыть сайт от поисковиков (для тестовых копий) |
| `ADMIN_PASSWORD` | `filarmonia2026` | пароль администратора при создании базы командой `seed` |

## Что осталось сделать

1. **Шрифты.** Cormorant Garamond и Golos Text подключены с Google Fonts
   (`filarmonia/templates/public/base.html`). Для российского хостинга их лучше положить
   локально: скачать `.woff2`, сложить в `filarmonia/static/fonts/`, заменить `<link>` на
   правило `@font-face` в `site.css`. Запасные шрифты уже прописаны — без интернета
   сайт остаётся читаемым.
2. **Билетная система.** Сейчас у события есть поле «Ссылка на покупку билета».
   Если у филармонии есть оператор (Ticketland, Радарио, Яндекс Афиша, собственная
   касса) — под него делается виджет или обмен данными вместо простой ссылки.
   Скажите, какой оператор, и я встрою.
3. **Перенос контента** со старого сайта: афиша, новости, документы, фотографии.
   Старый сайт на Drupal 7 — данные можно выгрузить из его базы и залить скриптом,
   это отдельная задача на пару часов.
4. **Юридические тексты.** Политика конфиденциальности, согласие на обработку
   персональных данных, уведомление Роскомнадзора — шаблоны страниц созданы,
   тексты нужно согласовать с юристом учреждения.
5. **Счётчики.** Яндекс.Метрика и, если требуется, виджет «Госуслуги. Решаем вместе» —
   код вставляется в конец `base.html`.
6. **Почта.** Сейчас обращения граждан сохраняются в базу и видны в админке.
   Если нужно дублировать письмом ответственному сотруднику — добавлю отправку
   через SMTP учреждения.
