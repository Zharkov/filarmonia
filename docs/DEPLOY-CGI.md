# Деплой на виртуальный хостинг через Apache CGI

Приложение запускается на виртуальном хостинге (PHP 5.5, нет native Python) через `index.cgi` и `mod_cgi`. SSH есть (включается в панели хостинга), поэтому миграции и разовые команды можно выполнять по SSH; базу также может заполнять само приложение при первом запросе (см. `AUTO_INIT_DB`).

## Подготовка

1. Установите Python (на Masterhost включается в панели «Python»).
2. Установите зависимости в папку с проектом:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте `.env` (копируйте `env.example`):

   ```bash
   cp env.example .env
   ```

   Заполните **обязательные** переменные:

   ```
   SECRET_KEY=ваш-секрет-ключ-минимум-32-символа
   ADMIN_PASSWORD=пароль-администратора
   ```

   Рекомендуется:

   ```
   AUTO_INIT_DB=1
   COMPRESS_RESPONSES=1
   ```

   `AUTO_INIT_DB=1` — при первом запросе приложение само создаст базу (миграции), администратора и структуру (настройки, страницы, меню, площадки, жанры, фестивали). Демо-контент не создаётся — добавляется через панель.

## Загрузка на хостинг

Загрузите **всё содержимое проекта** в корень домена (директорию, которую хостинг назначил для домена). В корне должны оказаться:

- `index.cgi`
- `.htaccess`
- `app.py`, `config.py`
- `filarmonia/` (пакет: `static/`, `templates/`, `admin/`, `models.py`, `seed.py`, `deploy_cgi.py`, …)
- `migrations/`, `instance/`, `filarmonia.db` (создастся автоматически)
- `.env`, `requirements.txt`

## Настройка

1. **Доступ к панели** (домен → «Настройки» → «Доступ по SSH» / «Python»). Включите Python и укажите путь к `python3`.
2. **Создайте `.env`** (в панели редактора или через FTP).
3. **Проверьте, что `index.cgi` executable** (права `755` или `+x`). Если не executable — дайте права через панель «Файлы» → правой кнопкой → «Изменить права».
4. **Откройте сайт**. При первом запросе (если `AUTO_INIT_DB=1`) приложение:
   - запустит миграции (создаст таблицы),
   - создаст администратора с паролем из `ADMIN_PASSWORD` (или `filarmonia2026` по умолчанию),
   - создаст структуру: настройки, страницы, меню, площадки, жанры, фестивали.

## Доступ к панели администратора

```
https://домен/admin/login
```

Логин: `filarmonia` (из `ADMIN_LOGIN`), пароль: из `ADMIN_PASSWORD`.

## Обновление

1. Обновите код (не коммитьте в гит).
2. Обновите зависимости: `pip install -r requirements.txt`.
3. Если изменилась схема — запустите миграции локально:

   ```bash
   python app.py db upgrade
   ```

   и загрузите обновлённый `filarmonia.db` (или временно включите `AUTO_INIT_DB=1` — приложение обновит схему при следующем запросе).
4. Очистите кэш браузера (статика версионная, но на всякий случай).

## Проблемы

| Симптом | Причина | Решение |
| --- | --- | --- |
| 500 / Internal Server Error | Ошибка в `.env` или конфиге | Откройте `index.cgi` напрямую в браузере — увидите ошибку |
| База пустая | `AUTO_INIT_DB=0` | Установите `AUTO_INIT_DB=1` в `.env` |
| Не создаётся админ | `ADMIN_PASSWORD` пуст | Установите пароль в `.env` |
| Статика не грузится | `.htaccess` не разрешает | Проверьте, что `filarmonia/static/` доступен и `.htaccess` правильный |
| 403 на `static/` | `FilesMatch` блокирует | Убедитесь, что расширения статики (.css, .js, .png, .mp4) не в списке запрещённых |
| `NameError: _env_loaded` | Старая версия `config.py` | Обновите `config.py` до последней версии |
| CGI не запускается | `AddHandler` не настроен | Убедитесь, что в `.htaccess` есть `AddHandler cgid-script .cgi` |

## Структура проекта на хостинге

```
домен/
├── index.cgi          # точка входа CGI
├── .htaccess          # роутинг и защита
├── app.py             # CLI (seed, migrate, test)
├── config.py          # загрузка .env
├── .env               # секреты (в .gitignore)
├── filarmonia/
│   ├── __init__.py    # create_app
│   ├── web.py         # хелперы, кэш, роуты
│   ├── models.py      # SQLAlchemy модели
│   ├── seed.py        # наполнение базы (python app.py seed)
│   ├── deploy_cgi.py  # автоинициализация при первом запросе
│   ├── static/        # раздаётся Apache напрямую
│   ├── templates/     # шаблоны
│   └── admin/         # панель управления
├── migrations/        # Alembic (не раздаются публично)
├── instance/          # папка для БД (не раздаётся публично)
└── filarmonia.db      # SQLite БД (создаётся автоматически)
```

## Локальная разработка

```bash
python app.py run          # запустить локально
python app.py seed --reset # наполнить базу
python app.py test         # прогонять проверки
python app.py db upgrade   # обновить схему
```

Локально используется `gunicorn` (см. `app.py`). На хостинге — только CGI.
