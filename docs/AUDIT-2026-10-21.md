## SEO

### 🔴
- SEO-1. Старые адреса Drupal (~1000: /poster/*, /news/*, …) — ПОЗЖЕ, при переезде.
- **SEO-2. Пустой SITE_URL** (`web.py:176`): canonical/sitemap/JSON-LD берут Host запроса
  (Host: evil.example → canonical http://evil.example/afisha). При SESSION_COOKIE_SECURE=1 или
  TRUST_PROXY=1 отказываться запускаться без SITE_URL (как `check_secret_key`, `__init__.py:177`);
  предупреждать, если SITE_NOINDEX=1 вместе с боевым SITE_URL.
- **SEO-3. Отменённый концерт = EventScheduled** (`schema.py:135`, `public.py:313`); на странице
  события отмены не видно, «Купить» активна. Сделать поле статуса у Event (scheduled/cancelled/
  rescheduled/postponed + previous_starts_at), eventStatus и previousStartDate в JSON-LD, плашка
  на странице события, скрыть «Купить» у отменённого; связать с «Изменениями в афише».
- SEO-4. Стенд: `Disallow: /` при SITE_NOINDEX мешает увидеть noindex (`public.py:661-663`) →
  разрешить обход + заголовок `X-Robots-Tag: noindex, nofollow` на все ответы (+ basic-auth, С-11).
